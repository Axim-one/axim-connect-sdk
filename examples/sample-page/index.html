Integration code (실제 API)


  


  

    이 페이지는 프론트엔드 시뮬레이션입니다. 실제 연동에서는 @axim/connect가 WalletConnect v2로
    Axim 앱과 페어링하고, 승인 시트는 실제 앱에서 표시됩니다. 트랜잭션 해시·주소·잔고는 데모용 가짜 값입니다.
  


  

    흐름 요약 — 연결(서명 없음) → 세션 인가(EIP-712 1회 = 소유증명 + 세션키 위임) → 입금(Kaia L1 approve+outboundTransfer, 가스는 Axim fee-delegation 스폰서 가능) → 출금(gas-free L2 서명 → AlphaSec가 L1 자동 정산).
